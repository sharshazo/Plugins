# Addons de LOTRO en español

## Guía de funciones actualizada — 17 de octubre de 2026

**[Ver la guía completa de todos los addons](GUIA_COMPLETA.md)**: interfaz, misiones, mapas, mecánicas de jefe, alertas propias, recolección, hazañas, JcJ, comandos, conexiones e instalación limpia.

- **QuestSync:** Buscar grupo usa el canal **LFF**, con lugar, tipo y tamaño de grupo; se envía al pulsar el botón.
- **Mapa del Mundo 3.20.0:** mecánicas por rol, cuatro modelos de aviso, alertas propias y recolección integrada.
- **LUI:** versión limpia, con interfaz, objetos, artesanía y efectos; Viaje y Bienes se retiraron.
- Descargas individuales y colección completa en **RAR y ZIP**, siempre con Turbine.

Para actualizar, reemplaza la carpeta anterior de cada addon con el juego cerrado; combinar archivos puede conservar componentes retirados. Conserva PluginData y los demás addons.

Colección de addons para **The Lord of the Rings Online** en español, pensados para funcionar juntos: un mapa del mundo interactivo, una interfaz con efectos animados, un asistente de misiones traducido, un seguimiento de hazañas y un addon de JcJ (PvMP). Cada carpeta ya tiene el **nombre exacto** que el juego necesita.

> Las animaciones de este README y de los README de cada addon son **recreaciones hechas con los gráficos reales de cada addon**. Las imágenes llamadas `captura_*` son **capturas del juego**.

## English summary

**Spanish-language LOTRO plugins (Lord of the Rings Online addons / Lua plugins)**: an interactive World Map with quest and deed markers, LUI (Geldahr's UI) with animated banners, QuestSync quest assistant with 14,000+ quests translated into Spanish, and Deed Tracker in Spanish. Install by copying the folders into `Documents\The Lord of the Rings Online\Plugins`.

## Instalación rápida

1. Botón verde **Code → Download ZIP** (o el ZIP de un solo addon, arriba).
2. Abre el ZIP. Dentro hay una sola carpeta (`Plugins-main`). Entra en ella.
3. Copia las **6 carpetas** que hay dentro (`LOTRO_Quest_Assistant`, `LUI`, `WorldMap_Addon`, `Turbine`, `CubePlugins`, `PvMP_Plus_Revisited`) y pégalas en:

   ```
   Documentos\The Lord of the Rings Online\Plugins\
   ```

   (con OneDrive: `OneDrive\Documentos\The Lord of the Rings Online\Plugins\`).
   Para actualizar, reemplaza las carpetas anteriores de estos addons con el juego cerrado; conserva PluginData y los demás addons.

   **No copies la carpeta `Plugins-main` entera**, solo las 6 de dentro. Debe quedar, por ejemplo:

   ```
   Plugins\LUI\LUI.plugin
   Plugins\LOTRO_Quest_Assistant\QuestSync.plugin
   Plugins\WorldMap_Addon\MapaDelMundo.plugin
   Plugins\CubePlugins\DeedTracker.plugin
   Plugins\PvMP_Plus_Revisited\PvMP+.plugin
   Plugins\Turbine\Class.lua
   ```

4. Abre LOTRO → **Opciones → Plugins** (o `/pluginmanager` en el chat) y activa los que quieras.

## Cómo se conectan

- **Mapa del Mundo ↔ QuestSync:** el mapa marca tus misiones activas con flechas y auras y se actualiza al aceptar, completar o abandonar.
- **Mapa del Mundo ↔ Deed Tracker:** las hazañas de cada zona están sincronizadas en los dos sentidos y se ven en el mapa (activas con aura, completadas en gris).
- **QuestSync ↔ Deed Tracker:** comparten la lectura del chat; el tracker muestra las hazañas en curso.
- **LUI ↔ QuestSync:** el cartel de misiones de LUI usa los mismos avisos del chat.

Cada addon funciona también solo.

---

## Problemas comunes

- **`Unable to resolve package ...`**: la carpeta quedó con otro nombre o dentro de otra carpeta. Revisa que quede como en el paso 3.
- **`attempt to call global 'class' (a nil value)`**: falta la carpeta `Turbine` dentro de `Plugins`.

## Narración por voz (opcional)

Los botones «Narrar» de QuestSync necesitan el programa [Narrador_IA](https://github.com/sharshazo/Narrador_IA), que se instala aparte (LOTRO no deja que un addon reproduzca sonido).
